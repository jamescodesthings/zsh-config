# functions everyday

> The zsh-config commands used day to day.

# Usage

- `j [query]` - jump to a folder from z's history
- `hist [query]` - search and tidy shell history
- `md [dir]` - make a folder with parents and cd into it
- `oh [dir]` - open a folder in QSpace Pro, Finder or `xdg-open`
- `zshconfig` - jump to or edit `~/.custom` (alias `zshc`)
- `zshenv` - edit this machine's `env.<hostname>.zsh`
- `reload [function]` - reload an autoloaded function without a new shell
- `picoh` - start PICO-8 with this folder as the cart root
- `start-workstation` - start the cloud workstation through GitHub Actions
- `test-color-24bit` - draw colour ramps to check truecolor
