# test-color-codes

> Draws every foreground and background pair of the 16 standard colours as a grid.

# Getting started

- `test-color-codes` - print the grid

# Options

- `[-h|--help]` - show this sheet

# See also

- `cheat test-color-names` - the colours by name
- `cheat test-color-24bit` - the truecolor ramps
