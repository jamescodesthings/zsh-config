# npm-update-latest

> Lists outdated npm packages and asks before moving each to `@latest`.
> A package that fails to update is listed at the end.

# Options

- `[-h|--help]` - show this sheet
- `[--plain]` - no colour

# Examples

- Walk the outdated packages:

`npm-update-latest`
