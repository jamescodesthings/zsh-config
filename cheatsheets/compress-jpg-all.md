# compress-jpg-all

> Runs `compress-jpg` on every JPEG in this folder that has no copy in `compressed/` yet.
> A failed file is listed at the end and the rest carry on.

# Options

- `[-h|--help]` - show this sheet
- `[--plain]` - no colour

# Examples

- Compress the folder:

`compress-jpg-all`

# See also

- `cheat compress-jpg` - one file
- `cheat compress-pdf-all` - the same for PDFs
