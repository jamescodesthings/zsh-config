# git-prune-local

> Delete local branches whose origin branch is gone (git branch -D).
> Lists them and asks first.

# Options

- `--plain` - no colour or animation
- `-q`, `--quiet` - print only warnings and errors
- Exit: 0 done, 1 failed, 2 wrong usage

# Examples

- List and prune:

`git-prune-local`
