# hist search

> Find a regex in all history, global first. Matches are highlighted and repeats grouped.
> Needs a query.

# Options

- `-q` - commands only, no directory headers

# Examples

- Search:

`hist search <regex>`

- Commands only:

`hist search <regex> -q`
