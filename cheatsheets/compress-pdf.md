# compress-pdf

> Shrinks a PDF with Ghostscript at the screen setting, into `compressed/` beside it.
> Needs gs.

# Getting started

- `compress-pdf <file>` - write `compressed/<file>`
- `compress-pdf-all` - every PDF in the folder

# Options

- `[-h|--help]` - show this sheet
- `[--plain]` - no colour

# Examples

- One document:

`compress-pdf report.pdf`
