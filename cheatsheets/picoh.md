# picoh

> Starts PICO-8 in the background with this folder as the cart root.
> Needs `PICO8` set to the PICO-8 binary.

# Getting started

- `picoh` - open PICO-8 here

# Options

- `[-h|--help]` - show this sheet
- `[--plain]` - no colour

# Variables

- `PICO8` - path to the PICO-8 binary

# See also

- `cheat pico-8` - PICO-8 itself
- `cheat zsh-config` - everything zsh-config gives you
