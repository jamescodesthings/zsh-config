# git lazygit

> A terminal UI for git: stage hunks, commit, rebase, resolve conflicts and push from one screen.
> Fast in big repos, since it shells out to git. Installed from the Brewfile.

# Usage

- `lazygit` - open it in this repo
- `space` - stage or unstage the file or hunk under the cursor
- `enter` - open a file to stage single lines
- `c`, `A` - commit; amend the last commit
- `P`, `p` - push; pull
- `e` - edit the file in your editor
- `?` - every key for the panel you are in
- `q` - quit

# Examples

- `lazygit log` - start in the log panel
