# compress-pdf-all

> Runs `compress-pdf` on every PDF in this folder that has no copy in `compressed/` yet.
> A failed file is listed at the end and the rest carry on.

# Options

- `[-h|--help]` - show this sheet
- `[--plain]` - no colour

# Examples

- Compress the folder:

`compress-pdf-all`

# See also

- `cheat compress-pdf` - one file
- `cheat compress-jpg-all` - the same for JPEGs
