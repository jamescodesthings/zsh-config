# confirm

> Ask y/n. Exit 0 on `y` or `Y`, 1 on anything else.

# Getting started

- `confirm` - ask with the default message
- `confirm "Delete this?"` - ask with your own message
- `if confirm "Continue?"; then rm -rf /tmp/myapp; fi` - guard a command
