# keys

> Key bindings across the terminal: kitty, fzf, the shell line, and the Stream Deck buttons.

# Getting started

- `ctrl+r` - fuzzy-search shell history
- `tab` - completion in fzf (fzf-tab); type to filter, enter picks
- `cmd+d`, `cmd+opt+arrows` - split the iTerm2 pane; move between panes

# fzf

- `ctrl+t` - pick files or folders, insert the paths at the cursor
- `alt+c` - pick a subfolder and cd into it

# Shell line

- `ctrl+a`, `ctrl+e` - start or end of the line
- `opt+left`, `opt+right` - back or forward one word
- `ctrl+w`, `ctrl+u`, `ctrl+l` - delete the word before the cursor; the line before it; clear the screen

# iTerm2

- `cmd+t`, `cmd+w` - new tab here; close it
- `cmd+shift+enter`, `cmd+shift+up` - zoom the pane; jump to the last prompt

# Stream Deck

- Mute, Camera, Jump to, Hang up - Google Meet buttons: mute, camera on or off, bring the Meet tab forward, leave the call; they need Accessibility for the Stream Deck app
