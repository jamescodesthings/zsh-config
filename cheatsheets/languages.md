# languages

> The languages, one sheet each: build, format, lint, debug and profile.

# Getting started

- `cheat java` - Java with Maven, Gradle or Bazel, google-java-format, JFR
- `cheat kotlin` - Kotlin with Gradle, ktfmt and detekt
- `cheat swift` - Swift with SwiftPM or Xcode, SwiftLint, LLDB and Instruments

# More

- `cheat go` - Go toolchain, golangci-lint and delve
- `cheat python` - uv, ruff, mypy and pytest
- `cheat typescript` - npm scripts, ESLint and Prettier
- `cheat grpc` - gRPC from the terminal

# See also

- `cheat platforms` - the iOS and Android platforms
- `cheat topics` - testing, debugging, deploy, data, review and more
- `cheat tools` - IDEs and build tools
- `cheat protobuf` - the proto3 language and protoc
