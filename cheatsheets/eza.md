# eza

> ls replacement. `ls` is aliased to `eza --group-directories-first` when eza is installed.

# Getting started

- `ls`: list, directories first
- `eza -la`: long list with hidden files
- `eza --tree --level=2 -l`: tree two levels deep, long format

- Next: add `--git` to see status.

# Options

- `-l`: long format
- `-a`: include hidden files
- `-h`: human-readable sizes (long format)
- `--git`: git status column (with `-l`)
- `--icons`: file icons
- `--sort=modified`, `--sort=size`: sort by that
- `--tree`: tree view
- `--level=<n>`: limit the tree depth
