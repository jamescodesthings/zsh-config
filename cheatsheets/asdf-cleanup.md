# asdf-cleanup

> Removes every installed asdf version except the global one in `~/.tool-versions`.
> It also removes versions a project pins: `update` keeps pinned versions.

# Options

- `[-h|--help]` - show this sheet
- `[--plain]` - no colour

# Examples

- Clean every plugin:

`asdf-cleanup`

# See also

- `cheat asdf` - the asdf aliases
- `cheat update` - cleans up with the pinned versions kept
