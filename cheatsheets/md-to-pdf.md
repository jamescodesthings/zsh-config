# md-to-pdf

> Convert markdown to an A4 pdf next to each input.
> Overwrites existing output. Needs pandoc, file and weasyprint.

# Options

- `--plain` - no colour or animation
- `-q`, `--quiet` - print only warnings and errors
- Exit: 0 done, 1 failed, 2 wrong usage

# Examples

- Convert one file:

`md-to-pdf notes.md`

- Convert several:

`md-to-pdf *.md`
