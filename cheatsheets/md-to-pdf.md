# md-to-pdf

> Convert markdown to an A4 pdf next to each input.
> Overwrites existing output. Needs `pandoc`, `file` and weasyprint. Exit 1 if any file failed, 130 on ctrl-c, which also stops a batch.

# Usage

- Convert one file, or several:

`md-to-pdf notes.md`

`md-to-pdf *.md`
