# aliases system

> Packages, containers, the OS and small shell helpers. Each is defined only where its tool or OS is.

# Usage

- `asch [word]` - grep the alias list
- `cl` - clear the screen
- `cht [name]`, `zshc` - cheat; zshconfig
- `apts [word]`, `apti [pkg]`, `aptu` - apt search; install; update and upgrade
- `snaps [word]`, `snapi [pkg]`, `snapr [pkg]` - snap find; install; remove
- `docker-stop-all`, `dsa` - stop every running container
- `dcup`, `dcdn` - docker compose up -d; down -v
- `ssh [host]`, `s [host]` - kitten ssh inside kitty
- `http`, `https` - httpie without certificate checks
- `pip` - python -m pip
- `bat` - batcat on Debian
- `gpt` - zev
- `pico`, `pico-8`, `pico8` - start PICO-8
- `xcode` - open Xcode (macOS)
- `rosetta [cmd]`, `rosetta-shell` - run under x86_64; an x86_64 zsh (Apple silicon)
- `unquarantine [file]` - clear the macOS quarantine flag
- `sleep-disable`, `sleep-enable` - stop and allow sleep (macOS)
- `av`, `av-all` - ClamAV scan here; scan everything
- `hlp` - list `/usr/local/bin` (zerocalc only)
- `wifi`, `battery` - wifi networks; battery detail (uconsole only)
