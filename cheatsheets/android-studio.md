# android-studio

> Android Studio for Android apps; Gradle drives the build.
> A top sheet, not a child of android.

# Getting started

- `studio [folder]` - open a project, once the command line launcher is installed
- `Sync Project with Gradle Files` - resync after editing build files
- `Device Manager` - create and start emulators

# Command line

- `./gradlew assembleDebug` - build a debug apk
- `./gradlew installDebug` - build and install on a device
- `./gradlew test` - run the unit tests

# Keys

- `cmd+shift+a` - find any action
- `shift shift` - search everywhere
- `cmd+b` - go to declaration
- `ctrl+r` - run; `ctrl+d` debugs
- `cmd+alt+l` - reformat the file
