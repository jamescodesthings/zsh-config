# functions cheat

> Show, render and check cheat sheets.

# Usage

- `cheat [words...]` - show a sheet, or tldr's page when none matches
- `cheat-help [tool] [words...]` - show a tool's sheet for `--help`
- `cheat-render [sheet]` - render a sheet in the palette
- `cheatsheet-test [--strict] [sheet|dir]` - check sheets render and keep the format
