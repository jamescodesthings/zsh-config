# get-hostname

> Prints the machine's short hostname: `uname -n` up to the first dot.
> Names the per-machine files such as `env.<hostname>.zsh`.

# Getting started

- `get-hostname` - print the short name

# Options

- `[-h|--help]` - show this sheet

# See also

- `cheat zshenv` - edit this machine's env file
- `cheat zsh-config` - everything zsh-config gives you
