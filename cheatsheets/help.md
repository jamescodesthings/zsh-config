# help

> The index of our own sheets. `cheat [name]` shows any sheet; `[tool] --help` shows a tool's own.
> Forgot what you are looking for? Getting started has the basics.

# Getting started

- `cheat setup`, `cheat keys` - how the config fits together; every key binding
- `cheat troubleshoot` - fixes for problems seen before
- `cheat` - list every sheet; `cheat search [word]` finds one; `[tool] --help` shows its own
- `ctrl+r` - fuzzy-search history for a command you ran before
- `j [name]` - jump to a folder: an alias, or z's best match
- `cheat functions` - every zsh-config command, in groups such as `cheat functions everyday`

# Everyday

- `tab` - completion opens in fzf (fzf-tab); type to filter, enter picks
- `ctrl+t`, `alt+c` - fzf: insert a path; cd into a subfolder
- `j alias add [name] .` - bookmark this folder, then `j [name]` jumps there
- `update` - keep the whole machine current

# Our tools

- `cheat hub` - the hub: one session steering a Claude session per repo
- `cheat hub task`, `cheat hub project` - Anytype tasks; projects and their map
- `cheat hub overview` - install, update, doctor, and the `cld` and `cldr` aliases
- `cheat skill` - the Claude skills, one sheet each
- `cheat readerr`, `cheat pkms` - hear selected text read aloud; the Anytype knowledge system
- `cheat zsh-config`, `cheat cli` - this shell setup; the house CLI helpers
- Third-party: `cheat fzf`, `cheat git`, `cheat eza`, `cheat bat`, `cheat glow`, `cheat http`, `cheat docker`, `cheat npm`, `cheat asdf`, `cheat apt`, `cheat zinit`, `cheat kitty`
