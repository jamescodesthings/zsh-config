# help

> The index of our own sheets. `cheat [name]` shows any sheet; `[tool] --help` shows a tool's own.

# Getting started

- `cheat` - list every sheet
- `cheat search [word]` - find a sheet by a word in it
- `cheat troubleshoot` - fixes for problems seen before
- `ctrl+r` - fuzzy-search history for a command you ran before
- `j [name]` - jump to a folder: an alias, or z's best match

# Finding your way around the shell

> when you need a key, a command or a folder

- `cheat setup` - how the config fits together
- `cheat keys` - every key binding
- `cheat functions` - every zsh-config command
- `cheat aliases` - every alias, most used first
- `tab` - completion opens in fzf (fzf-tab); type to filter, enter picks
- `ctrl+t` - fzf: insert a path
- `alt+c` - fzf: cd into a subfolder
- `j alias add [name] .` - bookmark this folder, then `j [name]` jumps there
- `cheat zsh-config` - see also

# Keeping the machine current

> once a day, or when something is out of date

- `update` - OS, package managers, languages, shell plugins and tools, in order
- `update --errors` - what the last run logged
- `cheat changes` - what changed lately in our tools
- `cheat update` - see also

# Working across repos with the hub

> when you steer a Claude session per repo

- `cheat hub` - the hub: one session steering a Claude session per repo
- `cheat hub action` - actions waiting on you
- `cheat hub project` - projects and their map
- `cheat hub overview` - install, update, doctor and the `cld` and `cldr` aliases
- `cheat updating` - keeping hub and its repos up to date
- `cheat skill` - the Claude skills

# Languages, platforms and topics

> when you need a language or platform's tooling

- `cheat bazel` - monorepo builds and tests
- `cheat languages` - java, kotlin, go, swift, python, typescript, grpc
- `cheat platforms` - ios, android
- `cheat tools` - idea, xcode, android-studio, buf, bazel
