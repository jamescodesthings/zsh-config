# test-color-24bit

> Draws red, green, blue and rainbow ramps in 24-bit colour, to check a terminal's truecolor.

# Getting started

- `test-color-24bit` - smooth bars mean truecolor works; bands mean it does not

# Options

- `[-h|--help]` - show this sheet
