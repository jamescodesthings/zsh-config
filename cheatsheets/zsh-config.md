# zsh-config

> James's shell setup, installed first on every machine and linked as `~/.custom`.
> macOS and Debian family only. Every tool below has a sheet: `cheat <name>`.

# Getting started

- `./install` - install everything (zsh, brew or apt tools, the `~/.custom` link)
- `update` - keep the whole machine current
- `cheat help` - the index of our sheets; `cheat functions` lists every function

# Our tools

- `cheat j`, `cheat hist` - jump to folders; search and tidy history
- Folders and markdown: `cheat oh`, `cheat md`, `cheat md-to-html`, `cheat md-to-pdf`
- Machine: `cheat update`, `cheat log`, `cheat config`, `cheat key`, `cheat wipcrypt`
- macOS terminal: `cheat iterm2`, `cheat iterm2 keys`, `cheat iterm2-settings`
- Linux: `cheat kitty` (terminal), `cheat gnome-bin` (window scripts)
- Reference: `cheat keys`, `cheat setup`, `cheat troubleshoot`, `cheat aliases`, `cheat changes`
- Sheets: `cheat cheat`, `cheat cheatsheet-test`, `cheat link-cheatsheets`, `cheat terminal-colors`, `cheat cli`
- Shell helpers: `cheat is`, `cheat confirm`, `cheat reload`, `cheat deps`, `cheat touch-sudo`
- Installer: `cheat install`, `cheat install-link`, `cheat install-box-config`, `cheat install-release`, `cheat link-blender-scripts`
- Git helpers: `cheat git-cleanup-branch`, `cheat git-prune-local`, `cheat git-i-really-fucked-up`, `cheat gcod`, `cheat gcom`
- Third-party tools: `cheat git`, `cheat docker`, `cheat fzf`, `cheat eza`, `cheat bat`, `cheat glow`, `cheat http`, `cheat npm`, `cheat apt`, `cheat asdf`, `cheat zinit`
- Small tools: `cheat aptr`, `cheat dsp`, `cheat picoh`, `cheat zshenv`, `cheat test-color-24bit`; notes: `cheat pico-8`, `cheat raspi`, `cheat zerocalc`
