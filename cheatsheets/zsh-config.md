# zsh-config

> James's shell setup, installed first on every machine and linked as `~/.custom`.
> macOS and Debian family only. Every tool below has a sheet: `cheat <name>`.

# Getting started

- `./install` - install everything (zsh, brew or apt tools, the `~/.custom` link)
- `update` - keep the whole machine current
- `cheat functions` - every function, by group; bare `cheat` lists every sheet

# Our tools

- `cheat j`, `cheat hist` - jump to folders; search and tidy history
- `cheat oh`, `cheat md` - open a folder; make one and cd into it
- `cheat md-to-html`, `cheat md-to-pdf` - convert markdown
- `cheat update`, `cheat log`, `cheat config` - updater; run logs; a tool's settings
- `cheat key`, `cheat wipcrypt` - per-project keys; encrypt and decrypt a tree
- `cheat kitty`, `cheat gnome-bin` - terminal keys; GNOME window scripts
- Sheets: `cheat cheat`, `cheat cheatsheet-test`, `cheat link-cheatsheets`, `cheat terminal-colors`, `cheat cli`
- Shell helpers: `cheat is`, `cheat confirm`, `cheat reload`, `cheat deps`, `cheat touch-sudo`, `cheat start-workstation`
- Installer: `cheat install`, `cheat install-link`, `cheat install-box-config`, `cheat install-release`, `cheat link-blender-scripts`
- Git helpers: `cheat git-cleanup-branch`, `cheat git-prune-local`, `cheat git-i-really-fucked-up`, `cheat gcod`, `cheat gcom`
