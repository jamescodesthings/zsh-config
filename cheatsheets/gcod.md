# gcod

> Checks out the gitflow develop branch, named by `git config gitflow.branch.develop`.

# Getting started

- `gcod` - check out the develop branch
- `git config gitflow.branch.develop <branch>` - set the branch name first

# Options

- `[-h|--help]` - show this sheet

# See also

- `cheat gcom` - the main branch
