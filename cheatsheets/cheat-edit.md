# cheat edit

> Open a local sheet in `$EDITOR` (micro when unset).
> Exit 1 if the sheet does not exist.

# Examples

- Edit a sheet:

`cheat edit git`

- Several words join with `-`, so this opens `git-commit.md`:

`cheat edit git commit`

# See also

- `cheat cheat new`: create a sheet first
- `cheat cheatsheet-test`: check it after editing
