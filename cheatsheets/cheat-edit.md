# cheat edit

> Open a local sheet in `$EDITOR` (micro when unset).
> Exit 1 if the sheet does not exist.

# Examples

- `cheat edit git` - edit a sheet
- `cheat edit git commit` - several words join with `-`, so this opens `git-commit.md`

# See also

- `cheat new <name>` - create a sheet first
- `cheat cheatsheet-test` - check it after editing
