# aliases npm

> npm shortcuts, defined when npm is installed.

# Usage

- `npmst`, `npmr [script]` - npm start; npm run
- `npmiy` - npm init -y
- `npmD [pkg]`, `npmS [pkg]` - install as a dev dependency; as a dependency
- `npmDE [pkg]`, `npmSE [pkg]` - the same, pinned to an exact version
- `npmil`, `npmDEl [pkg]`, `npmSEl [pkg]` - install with --legacy-peer-deps
- `npmg [pkg]`, `npmUG [pkg]` - install globally; uninstall globally
- `npmU [pkg]`, `npmUl [pkg]` - uninstall; uninstall with --legacy-peer-deps
- `npmL0`, `npmL0g` - top-level packages here; globally
- `npm-check-update`, `ncu` - pick updates interactively with npm-check
- `licensed` - npx licensed
