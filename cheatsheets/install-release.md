# install-release

> Install the latest GitHub release of a tool into `~/.local/bin`, no sudo. Debian only; on macOS it says brew owns the tool.
> Tools and asset names are listed in `configs/releases`.

# Usage

- Install or update one tool (prints `installed:` or `current:`):

`install-release glow`

- Show the usage:

`install-release --help`
