# apt

> Aliases and helpers zsh-config adds over apt. Defined only when `apt` is available.

# Commands

- `apti <package>`: `sudo apt install -y`
- `apts <query>`: `apt search -n`, search by name
- `aptu`: `sudo apt update && sudo apt upgrade -y`
- `aptr <package>`: `sudo apt remove -y`, then `sudo apt autoremove -y`

# Related commands

- `tldr apt`
