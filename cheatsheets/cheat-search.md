# cheat search

> Search sheet names, local and tldr. Needs a query; exit 1 without one.

# Examples

- `cheat search git` - search by part of a name

# Notes

- `[cheatsheet]` marks a local sheet, `[tldr]` a tldr page with no local sheet
- `nothing found` means no match
