# zerocalc

> ZeroCalc (PicoCalc device) keyboard shortcuts.
> The `zerocalc` host env is `env.zerocalc.zsh`.

# Getting started

- `F5` - toggle mouse mode, then `D-pad` moves the cursor
- `[` / `]` - left click, right click in mouse mode

# Navigation and selection

- `RSHIFT + left` / `RSHIFT + right` - home, end
- `RSHIFT + up` / `RSHIFT + down` - page up, down
- `RSHIFT + [` / `RSHIFT + ]` - file start, end
- `Ctrl + left` / `Ctrl + right` - jump by word
- `Alt + F` / `Alt + B` - word jump (readline)
- `LSHIFT + arrow` - select character
- `LSHIFT + RSHIFT + left` / `LSHIFT + RSHIFT + right` - select word
- `LSHIFT + RSHIFT + [` / `LSHIFT + RSHIFT + ]` - select to line start, end

# Right Shift

- `RSHIFT + A` / `RSHIFT + E` - line start, line end
- `RSHIFT + U` / `RSHIFT + K` - delete to line start, to line end
- `RSHIFT + W` - delete word back
- `RSHIFT + L` - clear screen
- `RSHIFT + C` / `RSHIFT + D` / `RSHIFT + Z` - interrupt, EOF, suspend
- `RSHIFT + key` - send Ctrl+key; add `LSHIFT` for Ctrl+Shift+key
