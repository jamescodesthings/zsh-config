# functions system

> Keep the machine current, clean up, and look after keys.

# Usage

- `update [name...]` - run the updaters in number order
- `asdf-cleanup` - remove every asdf version but the global one
- `npm-update-latest` - move outdated npm packages to `@latest`, asking each
- `aptr [package]` - remove an apt package, then autoremove
- `dsp` - stop Docker containers and prune the system
- `touch-sudo` - enable Touch ID for sudo on macOS
- `steamos-install` - reinstall what a SteamOS update wipes
- `get-hostname` - print the short hostname
- `key [create|cycle|pull|push|import|export|list|path] [name]` - per-project keys
- `wipcrypt [encrypt|decrypt|status|cycle-key]` - encrypt and decrypt a tree
