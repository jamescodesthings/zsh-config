# compress-jpg

> Shrinks a JPEG to 1200 pixels on the long side at quality 80, into `compressed/` beside it.
> Uses sips, so macOS only.

# Getting started

- `compress-jpg <file>` - write `compressed/<file>`
- `compress-jpg-all` - every JPEG in the folder

# Options

- `[-h|--help]` - show this sheet
- `[--plain]` - no colour

# Examples

- One photo:

`compress-jpg holiday.jpg`
