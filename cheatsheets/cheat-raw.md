# cheat raw

> Print a sheet's markdown, from the local sheet or else tldr.
> Exit 1 if neither has it.

# Examples

- `cheat raw git` - print a sheet's markdown
- `cheat raw git commit` - several words join with `-`
- `cheat git --raw` - the same through the show form

# See also

- `cheat edit <name>` - change the sheet
