# gcom

> Checks out the gitflow main branch, named by `git config gitflow.branch.main`.
> Falls back to `main` when it is not set.

# Getting started

- `gcom` - check out the main branch
- `git config gitflow.branch.main <branch>` - set the branch name

# Options

- `[-h|--help]` - show this sheet
