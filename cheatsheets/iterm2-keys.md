# iterm2 keys

> iTerm2's keys with the zsh-config profile and menu keys (`configs/iterm2/menu-keys`). Panes first.

# Panes

- `cmd+enter`, `cmd+shift+enter` - split side by side; split top and bottom (replacing `cmd+d` and `cmd+shift+d`)
- `cmd+ctrl+arrows` - go to the pane in that direction
- `cmd+[`, `cmd+]` - previous or next pane
- `cmd+opt+enter` - zoom the pane and back
- `ctrl+opt+arrows` - resize the pane
- `cmd+w` - close the pane

# Tabs and windows

- `cmd+t`, `cmd+n` - new tab in this folder; new window
- `cmd+shift+[`, `cmd+shift+]` - previous or next tab
- `cmd+1` to `cmd+9` - pick a tab
- `cmd+ctrl+f` - full screen
- `opt+space` - the hotkey window

# Editing and finding

- `opt+left`, `opt+right`, `opt+backspace` - back, forward or delete one word
- `cmd+left`, `cmd+right`, `cmd+backspace` - start or end of the line; delete to the start
- `cmd+f`, `cmd+k` - search the scrollback; clear
- `cmd+;`, `cmd+shift+;`, `cmd+shift+h` - autocomplete; command history; paste history
- `cmd+opt+b` - instant replay
- `cmd+shift+up`, `cmd+shift+down` - jump between prompts (shell integration)
- `cmd+click` - open a link or file; select to copy

# Notes

- Swapping panes has no menu item and needs iTerm2's key-binding action; set it in Settings, Keys, Key Bindings if wanted
- `ctrl+up` and `ctrl+down` stay with Mission Control and App Exposé
