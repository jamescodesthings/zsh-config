# aliases

> Every alias zsh-config and the hub define, with the git ones from the oh-my-zsh git plugin that get used most.
> `asch [word]` greps the live list; an alias that needs a missing tool is not defined.

# Getting started

- `cldr`, `cld` - resume a Claude session; start one (asks first if this repo has one open)
- `gst`, `gp`, `gl` - git status; push; pull
- `gcm [message]` - git commit with a message
- `gco [branch]`, `gd` - git checkout; git diff
- `root` - cd to the top of this git repo
- `lla`, `l` - list with hidden files; list as a tree
- `cht [name]`, `zshc` - cheat; jump to the zsh config

# Groups

- `cheat aliases git` - git, from zsh-config and the oh-my-zsh git plugin
- `cheat aliases claude` - Claude Code, from the hub
- `cheat aliases files` - listing, copying, opening and clipboard
- `cheat aliases npm` - npm and node
- `cheat aliases system` - apt, snap, docker, macOS, Linux and the rest
