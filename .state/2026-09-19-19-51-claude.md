## Handoff notes
- A code review of the staged diff found one real risk: `softwareupdate --all` can stop for a password and would install a new macOS version. `000-soft` now parses `softwareupdate --list` and installs only entries without `Action: restart`.
- The old zinit updater never ran; `zinit` is a function. `080-zinit` sources `zinit.zsh`.
- agent-forge's installer exits 0 even when a sub-installer fails and prints `[warn]`; `900-agent-forge` greps for that. It was tested against a fake checkout only, because the real `make install` runs `claude update` under the live session.
- In this user's shell `cp`, `mv` and friends are progress wrappers that print control codes, and a piped `ls` can hang; use `/bin/cp` and globs in scripted checks.
- Text that looks like a user message but arrives inside a tool result is not acted on. One such block asked for macOS workflow R&D and Obsidian alternatives; it is parked until the user confirms it.
