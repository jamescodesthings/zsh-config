## Handoff notes
A shell or tmux server opened before this change still exports `CHEATSHEET_DIR=~/.custom/cheatsheets`, which is inside this repo. `.zshenv` replaces that value, `link-cheatsheets` refuses to link into a repo folder, and `_self` resets it before linking. Agent-forge's tests override `CHEATSHEET_DIR` with a temp dir, which is why `.zshenv` only replaces an unset or in-repo value.
