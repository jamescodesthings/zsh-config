## Handoff notes
- A zsh trap's `return N` does not survive a `$(...)` command substitution; `md-to-pdf` sets a flag in the trap and checks it after every step instead.
- `(( n++ ))` returns the old value, so `ok && ... || bad` fires both branches when n is 0; the test scripts use `(( n += 1 ))`.
- pandoc resolves embedded images against the current directory unless `--resource-path` is given.
